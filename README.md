# KosFinder

Aplikasi Flutter untuk pencarian dan pengelolaan kos dengan Supabase.

## Deskripsi
KosFinder adalah aplikasi mobile Android untuk menemukan dan mengelola kos (rumah sewa) berbasis Flutter. Menggunakan Supabase sebagai backend untuk autentikasi, penyimpanan data, dan penyimpanan gambar.

## Fitur
- Daftar kos dengan nama, harga, alamat ringkas, dan status aktif
- Pencarian dan filter berdasarkan nama, area, fasilitas, dan rentang harga
- Urutan hasil berdasarkan harga terendah atau terbaru
- Login pemilik dengan email‑password atau Google
- Pemilik dapat menambahkan, mengubah, menyembunyikan (soft‑delete) kos miliknya
- Row‑Level Security (RLS) pada Supabase memastikan tiap pemilik hanya dapat mengubah data miliknya
- Kelola tipe kamar dan status ketersediaan (bonus)


## Batasan versi
- Flutter SDK >= 3.10.0
- Dart SDK >= 2.19.0
- Android SDK 31+ (untuk build APK)

## Catatan keamanan
File `.env` berisi kunci publik (anon key) yang **tidak bersifat rahasia** tetapi tetap tidak disimpan di repository. Pastikan tidak ada kunci `service_role` atau kredensial lain yang ter‑commit.
