# Test Plan KosFinder

Dokumen rencana pengujian manual aplikasi Android KosFinder berdasarkan seluruh Acceptance Criteria (AC) di [docs/PRD.md](PRD.md), termasuk skenario negatif (hasil kosong, tanpa internet, input tidak valid, dan pemilik lain mencoba mengubah data).

- **Target perangkat:** Android 8.0 atau lebih baru.
- **Konfigurasi:** Jalankan aplikasi dengan `--dart-define=SUPABASE_URL=<url>` dan `--dart-define=SUPABASE_ANON_KEY=<anon-key>`.
- **Catatan pengisian:** Kolom **Hasil nyata** dan **Lulus** dibiarkan kosong untuk diisi saat eksekusi pengujian pada perangkat.

| TP-01 | US01-AC1 | 1. Buka aplikasi dalam kondisi belum login.<br>2. Pilih tab/mode **Daftar**.<br>3. Masukkan email baru yang valid dan kata sandi valid.<br>4. Tekan tombol daftar. | Akun berhasil dibuat dan pengguna langsung masuk ke halaman Daftar Kos tanpa diminta verifikasi email. | | |
